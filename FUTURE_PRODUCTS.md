# Future Products

The embeddable website translator is now an implemented product, not future work. It includes customer provisioning, domain locking, plan entitlements, usage metering, key rotation, administrator controls, and WordPress/Webflow/plain-HTML support.

Potential future additions should preserve Supabase Auth, direct Stripe Billing, RLS, shared approved language knowledge, and privacy controls. Candidates include team workspaces, an authenticated developer API with scoped keys, batch document translation, organization-level usage allocation, expanded language directions after approved knowledge coverage, and advanced analytics. None of these should be advertised as available until implemented and tested.
